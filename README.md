# Vue 3 + Vite

This template should help get you started developing with Vue 3 in Vite. The template uses Vue 3 `<script setup>` SFCs, check out the [script setup docs](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) to learn more.

Learn more about IDE Support for Vue in the [Vue Docs Scaling up Guide](https://vuejs.org/guide/scaling-up/tooling.html#ide-support).

## Vue DevTools Integration

This project includes Vue DevTools integration for enhanced development experience:

### Usage
1. **Browser Extension**: Install the Vue DevTools browser extension for Chrome/Firefox
2. **Standalone DevTools**: Access the standalone DevTools at `http://localhost:7777/__devtools__/` when running the dev server
3. **Keyboard Shortcut**: Press `Alt + Shift + D` in the application to toggle Vue DevTools

### Development Server
```bash
pnpm dev
```

The Vue DevTools will be automatically available during development with debugging capabilities for:
- Component inspection
- Vuex/Pinia state management
- Vue Router navigation
- Performance profiling
- Timeline events
